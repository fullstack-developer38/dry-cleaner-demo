Security and offline operation

Built for a live POS and real money

Unknown payment results are held and checked, never shown as paid. If a store loses internet, its POS keeps trading.

Outbound-only connector

The store connector opens every connection itself. SQL Server is never exposed.

No card data stored

Hosted payment form online, terminals in the store. No card numbers in our systems.

Offline Safe Mode

Online payments pause for that store only and reopen after reconciliation.

Merchant isolation

Each merchant sees only its own data. A changed ID returns nothing.
